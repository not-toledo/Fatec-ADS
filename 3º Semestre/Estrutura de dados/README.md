## 📝 Critérios de Avaliação

A média final do semestre é calculada pela seguinte fórmula:

$$\text{Média Final} = \frac{(P1 \times 4) + (P2 \times 4) + (\text{SEM} \times 2)}{10}$$

* **P1:** Prova do 1º Bimestre  
* **P2:** Prova do 2º Bimestre  
* **SEM:** Nota de Atividades/Seminários
